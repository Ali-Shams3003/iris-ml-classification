# iris-ml-classification
# Iris EDA and Classification

A complete Machine Learning project on the Iris Dataset using Python.  
This project includes Exploratory Data Analysis (EDA), data visualization, dimensionality reduction, multiple ML algorithms, ROC-AUC evaluation, and JSON result export.

---

# Project Overview

This project analyzes the famous Iris flower dataset and builds classification models to predict flower species based on flower measurements.

The project covers:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature correlation analysis
- Data visualization
- Multiple ML model training
- ROC Curve and AUC Score evaluation
- 3D UMAP visualization
- JSON result generation

---

# Dataset

Dataset used: Iris Dataset

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:
- Iris-setosa
- Iris-versicolor
- Iris-virginica
